# Scientific-Calculator


Vania JavaScript Scientifit Master Calculator
A modern and responsive **Scientific Calculator** built using **HTML, CSS, and JavaScript**. This project performs both basic and advanced mathematical calculations through an intuitive user interface, making it useful for students, developers, and anyone who needs quick mathematical computations.

# Demo Link : https://scientifica.netlify.app/

##  Features

### Basic Operations

* Addition (+)
* Subtraction (-)
* Multiplication (×)
* Division (÷)
* Percentage (%)

### Scientific Functions

* Square Root (√)
* Power (xʸ)
* Exponentials
* Logarithms (log, ln)
* Factorial (n!)
* Trigonometric Functions

  * sin()
  * cos()
  * tan()
* Parentheses Support
* Decimal Calculations

### User Interface

* Responsive Design
* Clean and Modern Layout
* Easy-to-Use Button Controls
* Fast Real-Time Calculations

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

##  Getting Started

### Clone the Repository

```bash
git clone https://github.com/Aditya001-bit/Scientific-Calculator.git
```

### Navigate to the Project

```bash
cd Scientific-Calculator
```

### Run the Project

Simply open the `index.html` file in your browser.
